- Enterprise RAG assistant for 200+ employees (Azure AI Foundry, RAGAS evaluation)

- Two arXiv preprints on mobile UI understanding
- iOS-1K Mobile UI Dataset on Hugging Face (11K+ downloads)

## Tech

Static site built with plain HTML, CSS, and JavaScript. No framework and no build step.
Responsive layout, light/dark theme, and accessible markup. Hosted on GitHub Pages.


## Run locally

```bash
git clone https://github.com/atharparvezce/atharparvezce.github.io.git
cd atharparvezce.github.io
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
